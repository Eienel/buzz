# BUZZ brand assets

The mark is a seven-cell honeycomb: six dead combs outlined in slate, one alive
in amber. It is the game in one glyph, and it stays legible down to 32px.

| File | Size | Use |
|---|---|---|
| `buzz-token-1000.png` | 1000x1000 | Token image (ClawPump / pump.fun) |
| `buzz-avatar-400.png` | 400x400 | X profile picture |
| `buzz-banner.png` | 1500x500 | X header |
| `buzz-wordmark.png` | 1200x360 | Docs, decks, README headers |
| `buzz-mark-512.png` | 512x512 | Transparent mark |
| `buzz-mark-180.png` | 180x180 | Small transparent mark |
| `buzz-mark-32.png` | 32x32 | Favicon |
| `*.svg` | vector | Source, edit these and re-render |

Palette: background `#0b0e14`, amber `#ffb454` to `#ff8c2f`, dead cell strokes
`#38425c` and `#252d40`, body text `#e8edf6`, muted `#8b96ab`.

The mark sits inside a circular safe area, so a round crop (X avatar) does not
clip the outer cells.
